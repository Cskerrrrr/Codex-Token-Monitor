# Codex Token Monitor

Windows 上的 Codex 用量统计与悬浮额度球。

## 下载与运行

从 [最新版本](https://github.com/Cskerrrrr/Codex-Token-Monitor/releases/latest) 下载 `CodexTokenMonitor.exe`，放在个人可写文件夹中运行。程序会在旁边的 `data` 文件夹保存设置和本机索引。

也可下载 `CodexTokenMonitor-portable.zip`，完整解压后运行其中的 EXE。支持 Windows 10 / 11 x64。

1. 使用本机 Codex 的 ChatGPT 登录状态；需要切换账号时，在统计页点击“切换 ChatGPT 账号”。这也会切换本机 Codex 使用的账号。
2. 悬浮球显示总 Token 估算、当前周使用 Token、预计总费用和已用额度。外圈从 0% 增长至 100%；满圈表示额度用完。
3. 托盘菜单可打开详细统计、设置开机启动、检查新版本及退出。

## 统计与费用

- 默认展示本次额度重置后的数据，支持同一登录账号的设备汇总。
- 最近调用显示模型、实际记录的推理强度、输入、缓存读取、缓存写入、输出和费用明细；未记录的强度显示“未记录”。
- 按 Sub2API 价格与规则估算普通输入、缓存和输出费用。长上下文等规则以可获取的模型和日志字段为依据。
- 输入 Token 已包含缓存读取，输出 Token 已包含推理 Token，两者不再次加入 Token 总数。
- 费用为 API 等价估算，**不是 ChatGPT 订阅实际账单**。日志没有提供的服务档位、工具或多模态计费单位，无法准确还原。
- 额度推算基于已有用量与账号消耗比例，属于估算值；刚重置或样本较少时会有较大波动。
- v1.0.4 起，“预计总费用”采用 [Sub2API 的 7 天窗口算法](https://github.com/Wei-Shaw/sub2api/blob/9a62841fd124d026cf3694fcf9b79e98addcdbdc/frontend/src/components/account/AccountUsageCell.vue#L812)：本次重置后账号累计费用 × 100 ÷ 每周已用百分比。使用未舍入费用计算，包含缓存费用；费用或百分比为 0 时显示 `—`。页面和悬浮球使用同一计算口径，新增记录即时累计。

## 版本更新

从 v1.0.2 起，客户端通过更新服务器接收新版本通知，**检查更新不调用 GitHub API**。在线同步时通知随下一次同步返回；未登录或手动检查时向更新服务器查询。有新版本时提示“立即更新 / 稍后提醒”，由用户决定是否安装。也可从托盘关闭自动检查。

用户确认后，客户端从本仓库的 GitHub Release 下载对应版本 EXE。更新后保留账号配置和统计数据。

v1.0.6 起，更新服务器连接失败时会尝试备用下载通道；检查更新仍不调用 GitHub API。多设备首次同步会跳过服务器已确认的旧周期记录，并在补传过程中显示账号汇总。

仓库说明文件的编辑不会触发客户端更新；维护者发布带完整签名安装包的新版本后，客户端才提示更新。服务器每分钟核对一次签名发布清单，也支持发布流程完成后立即通知。旧版若无法检查更新，请先退出托盘程序，下载 EXE 覆盖原文件，再启动；保留原 `data` 文件夹。

## 隐私与安全

同步按登录账号隔离。上传 Token 数、模型、推理强度、调用时间及额度快照等统计字段，不上传提示词、回答或本机文件路径。登录身份凭证仅用于服务器验签，不持久化保存；OpenAI 访问凭据和刷新凭据保留在本机 Codex。

本仓库只公开安装包、版本信息及使用说明。

## Excel 桥接（1.2.0）

右键托盘 → **Excel 桥接 → 启用桥接**。初次启用会准备随 EXE 内置的组件，无需另外安装 Python。启用后完全退出并重新打开 Codex，再选择 Excel 模型。停止桥接后同样需要重启 Codex。

- 统计页地址为 `http://127.0.0.1:18765/`。桥接默认使用 `http://127.0.0.1:8765/v1`，可在“桥接设置”里修改端口、默认模型、登录来源和代理。
- 选择“随监控启动桥接”可在下次打开监控时自动启用；开机启动仍由主托盘菜单控制。默认首次安装不启用桥接。
- 默认优先使用本机 Codex 的 ChatGPT 登录，支持 Excel 加载项登录。需要时点击“打开 Excel 登录”，在桌面版 Excel 的官方 ChatGPT 加载项完成登录。
- 启停时自动应用和恢复本工具管理的 Codex 配置；端口被占用时会提示，不会关闭其他程序。已单独运行上游桥接的用户应先退出原桥接。
- 本功能集成 [excel-codex-bridge 0.5.18](https://github.com/Kaixxrua/excel-codex-bridge)，属于非官方功能；登录可用性和模型响应仍取决于上游服务。桥接请求直接发送到上游服务，用量同步服务器仅承担原有统计同步。
- 图片、工具调用等桥接能力由内置组件提供；本工具的用量统计仍采集 Codex 生成的日志。
